## Пункты задания → файлы

### п.1 Регистрация (`/register`)
- `RegisterPage.jsx` — подписи полей, ссылка «Уже зарегистрированы?» → наоборот: на login «**Еще не зарегистрированы? Регистрация**»
- `client/src/utils/validation.js` + `server/utils/validation.js` — логин `[a-zA-Z0-9]{6,}`, пароль `min 8`
- `server/routes/auth.js` — INSERT users

### п.2 Вход (`/login`)
- `LoginPage.jsx` — текст ошибок, ссылка на регистрацию
- `server/routes/auth.js` — POST /login

### п.3 Личный кабинет (`/requests`)
- `RequestsPage.jsx` — «история бронирований», **слайдер** (можно вынести компонент с лендинга)
- **ДОБАВИТЬ:** таблица/поле `reviews` в БД, форма отзыва если статус ≠ `new` (после действия админа)
- `server/db/schema.sql` — комментарий про `reviews`

### п.4 Оформление заявки (`/requests/form`)
- `RequestFormPage.jsx` — select помещений, дата **ДД.ММ.ГГГГ**, оплата
- `server/db/seed.sql` — 4 типа помещений
- убрать/не показывать «Иная услуга»

### п.5 Админ (`/admin`)
- `server/db/init.js` — **Admin26** / **Demo20**
- `AdminPage.jsx` — статусы только «Банкет назначен», «Банкет завершен» (+ изначально «Новая»)
- **ДОБАВИТЬ:** фильтр по статусу, сортировка, пагинация (комментарии в AdminPage.jsx)

### Лендинг (`/`)
- `LandingPage.jsx`, `HeroSlider.jsx` — тексты про банкеты, **4** картинки, интервал **3000** мс
- `client/public/images/` — slide-1…slide-4.png

### Модуль 2
- HTML-макеты 390×844 в Figma, не обязательно в репозитории
- `RESPONSIVE.md` — мобильный дизайн

### Модуль 3
- `schema.sql` — отзывы, при необходимости убрать `cancelled`
- `index.css` — микроанимации уже есть (animate-fade-up)

## Статусы в БД (schema.sql + routes)

```
new              → «Новая»
in_progress      → «Банкет назначен»   (переименовать LABEL, не обязательно ключ)
completed        → «Банкет завершен»
cancelled        → убрать из CHECK или не показывать в админке
```

В `server/routes/requests.js` и `admin.js` — `STATUS_LABELS`.  
В `RequestsPage.jsx` — `statusColors`.

## Порядок работы на экзамене (≈30–60 мин только тексты)

1. `Layout.jsx` + `LandingLayout.jsx` — название **Банкетам.Нет**
2. `init.js` — Admin26 / Demo20 → `npm run db:init`
3. `seed.sql` — помещения
4. `validation.js` (×2) — логин/пароль
5. Все `pages/*.jsx` — заголовки и кнопки
6. `STATUS_LABELS` + админ-кнопки
7. Картинки в `public/images/` + `images.js`
8. По времени: отзывы, фильтры админа, 4-й слайд
